# EcoPoints: gotchas

1. **Supabase grants everything in `public` to anon/authenticated by default.** The migration revokes it all at the end and re-grants exactly what's needed. Any new table or function needs the same treatment: enable RLS, add a SELECT policy if clients read it, and `revoke … from public, anon, authenticated` on new functions, then grant only what's intended. Re-run `supabase/tests/ecopoints_checks.sql` after any schema change.
2. **Function bodies use `set search_path = ''`.** Fully qualify everything (`public.classes`, `auth.uid()`), or the function fails at runtime, not at creation.
3. **Next.js 16:** `middleware.ts` is now `src/proxy.ts`, and `params`/`searchParams`/`cookies()` are async. The scaffold's `cacheComponents` / `partialPrefetching` are deliberately **off**: every page is live data and they'd force Suspense boundaries everywhere. Bundled docs are in `node_modules/next/dist/docs/`.
4. **PINs are 6 digits**, not 4: Supabase Auth's minimum password length is 6.
5. **Monitor login addresses** are `ecopoints-m-<class uuid>@<MONITOR_EMAIL_DOMAIN>`. No email is ever sent. Changing `MONITOR_EMAIL_DOMAIN` after PINs exist breaks those logins (reset each PIN to recreate).
6. **Checklist edits are forward-only.** An item's code, type (count / yes-no) and who answers are fixed once created, because past answers depend on them. Label, points, SDGs, order and on/off can change; past points don't.
7. **Closing a month is permanent.** Void or adjust first. The database refuses any points row dated in a closed month.
8. **"Today" comes from the database** in the school's time zone (`schools.timezone`, default Asia/Dubai), never from the server clock.
9. **Login rate limiting:** monitor/teacher sign-in goes through a server action, so Supabase's per-IP auth limits see Vercel's IP, not the student's. Low risk for a pilot (a class login only reaches eco points), but if this goes wider, add attempt throttling or move sign-in to the browser client.
10. **Server-action success messages vanish** when the action changes what the page shows (e.g. closing a month replaces the button with the result). That's expected.
11. **`NEXT_PUBLIC_SCHOOL_SLUG` is the school's short code (`school` from seed.sql), not its name.** The name ("Credence High School") lives in the database and is changed in Teacher → Settings or with `update public.schools set name = … where slug = 'school'`. The code must match `^[a-z0-9-]{2,40}$`.
12. **Windows + Node scripts:** don't call `process.exit()` right after closing a readline interface. Node can crash with `Assertion failed: !(handle->flags & UV_HANDLE_CLOSING)`. Set `process.exitCode` and return instead (as `scripts/create-teacher.mjs` does).
13. **AI counts are approximate.** Vision models miscount crumpled or overlapping items. That's why a mismatch is a *flag for review*, never an automatic penalty, and why the pilot compares AI counts against hand counts before any accuracy figure is quoted.
14. **Gemini free tier vs paid tier:** free-tier prompts and photos may be used by Google to improve its products and seen by human reviewers. Use a paid-tier key (billing linked) for anything from the school. Develop with staged photos only on the free tier.
15. **Model IDs change.** `GEMINI_MODEL` / `ANTHROPIC_MODEL` are environment settings so a renamed or retired model is a settings change, not a code change. If AI checks start failing with a 404, check the model ID first. Default is `gemini-3.5-flash-lite` (small, cheapest); `GEMINI_FALLBACK_MODEL` (e.g. `gemini-3.8-flash`) is tried once automatically if the main model fails for any reason other than a bad key. Each model has its own usage limits, so this is the competition-day safety net.
19. **AI errors are shown on screen as they are** (e.g. "API key not valid", "Resource has been exhausted", "AI isn't set up"). Fine for a prototype; tone it down before real users. Changing `.env.local` needs `npm run dev` restarted to take effect.
16. **Photo upload size:** server actions accept 1 MB by default; `next.config.ts` raises it to 3 MB. Photos are shrunk on the device to ≤ 1288 px JPEG first (usually under 0.5 MB). Don't remove the shrink step.
17. **The bin check needs today's class check first** (it uses that day's "students present" and plastic-free count). The room photo needs the peer check first. Both are one per class per day; a teacher void allows a retake.
18. **`public_school` was redefined in the AI migration** (it now also returns AI settings). If you edit it again, edit the newest definition.
